# StudySathi team voice recording kit

Record these short scripts in your own voice. No account or API key is needed.

## How to record

1. Use a quiet room and a phone recorder. Speak warmly and clearly, with a short pause between the question and each choice.
2. Record each script as a separate clip. Use the exact name below, ending in `.mp3` or `.wav`. Renaming a different format does not convert it. If your phone saves M4A, export it as MP3 or WAV first.
3. One person can read English and another Nepali. Listen back together and correct pronunciation or missing words. Record only voices your team agrees to publish.
4. Put finished files in a folder, then tell the developer where it is. Partial batches are fine. Never send passwords or API keys.

## Developer import

Preview: `npm.cmd run import:game-audio -- --from "C:\path\to\recordings"`

Import after listening: `npm.cmd run import:game-audio -- --from "C:\path\to\recordings" --import`

The importer accepts only known script names and MP3/WAV media, copies content-hashed files into public/audio/games, and labels them Voice: StudySathi team. No API requests, subscriptions or third-party generation. Rebuild and publish after import. Text remains available when no recording exists.
